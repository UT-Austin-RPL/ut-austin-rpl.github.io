Embodied First Exam brings together 1,156 tasks across 47 robots. A coding agent can issue individual actions, write a controller, or train a policy. In the standard setting the agent observes the robot through its sensors and gets one attempt by default. The real-time variant keeps the simulation running while the agent reasons. On the 456 core tasks, the strongest of the eight agents tested solved 34% in the standard setting.
